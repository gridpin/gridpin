# Code of Conduct

This project follows the spirit and the text of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive; harassment, personal attacks,
discriminatory remarks and sustained disruption are not tolerated — in issues,
pull requests, discussions and any other project space.

**Reporting.** Violations can be reported privately to
[contact@gridpin.dev](mailto:contact@gridpin.dev). Reports are reviewed by the
maintainers; reporter identity is kept confidential. Consequences range from a
warning to a permanent ban from project spaces, at the maintainers' discretion,
following the enforcement ladder described in the Covenant.

For the full standard — definitions, scope and the enforcement ladder — the
linked Contributor Covenant 2.1 text is authoritative.
