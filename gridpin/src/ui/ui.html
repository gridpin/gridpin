Geocode a CSV

The file stays on this machine: rows go to this server's /v1/geocode, 500 at a time, and come back with gp_lat, gp_lon, gp_match_level, gp_weak, gp_confidence and the address found. The delimiter (comma, semicolon or tab) is read from the header row and kept in the file you download. A cell longer than 1024 bytes is not sent: its row comes back empty with too_long. On a server of several countries, open /ui?country=de to ask one country's sheet.
