# Security Policy

## Supported versions

Only the latest release receives security fixes. Please update to the newest release before reporting.

## Reporting a vulnerability

Report vulnerabilities privately to **security@gridpin.dev**. Please do not open a public issue for security problems.

Include what you found, how to reproduce it, and the GridPin version affected. You will get a reply as fast as a solo maintainer can manage — usually within a few days.

## Bounty

There is no bug bounty (this is a solo project). Reporters are acknowledged in the release notes for the fix, unless they prefer to stay anonymous.
