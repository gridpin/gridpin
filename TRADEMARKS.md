official data sheets. The Apache-2.0 license of this repository covers the
**code** — it does not grant rights to the name or the logo.

- state truthfully that your software uses GridPin, is built on GridPin, or is
  compatible with GridPin ("powered by GridPin");
- use the name in articles, benchmarks, reviews and academic work;
- keep the package/crate/extension names (`gridpin`, `gridpin_ext`) as
  dependencies of your project.

- use the GridPin name or logo as the name or logo of a fork, a derived
  product, a data service, or a company;
- publish modified builds or modified data sheets under the GridPin name in a

- register domains, accounts or packages whose names imply they are the
  official GridPin project.

A fork of the code is welcome under Apache-2.0 — under its own name.
